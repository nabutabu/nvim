# nvim

My Neovim configuration.

## Plugins

- [lazy.nvim](https://github.com/folke/lazy.nvim) — plugin manager
- [catppuccin](https://github.com/catppuccin/nvim) — colorscheme
- [telescope.nvim](https://github.com/nvim-telescope/telescope.nvim) — fuzzy finder (with plenary and fzf-native)

## Keybindings

- `<C-p>` — find files
- `<Space>fg` — live grep
